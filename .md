Tolong buatkan proyek dashboard monitoring IoT sederhana menggunakan Vite + Vue 3 (Composition API dengan <script setup>) yang terhubung ke Supabase.

Spesifikasi & Langkah Pengerjaan:

1. Inisialisasi Proyek:
   - Buat proyek baru menggunakan Vite dengan template Vue (JavaScript).
   - Install dependencies: `@supabase/supabase-js`.

2. Konfigurasi Environment:
   - Buat file `.env` di root proyek dengan variabel:
     VITE_SUPABASE_URL=https://gqfzbmvctuxmakqxrrri.supabase.co
     VITE_SUPABASE_ANON_KEY=GANTI_DENGAN_SUPABASE_PUBLISHABLE_KEY_ANDA

3. Klien Supabase:
   - Buat file `src/lib/supabaseClient.js` untuk inisialisasi klien Supabase menggunakan `createClient` dari `@supabase/supabase-js`.

4. Komponen Utama (src/App.vue):
   - Gunakan Vue 3 `<script setup>`.
   - Ambil 10 data riwayat terakhir dari tabel `telemetri_trafo` saat komponen dimuat (`onMounted`) diurutkan berdasarkan `timestamp desc`.
   - Buat subscription Supabase Realtime pada tabel `telemetri_trafo` (event `INSERT`) agar setiap ada data baru dari ESP32/EMQX, data langsung muncul di paling atas daftar secara otomatis.
   - Bersihkan channel realtime saat komponen dilepas (`onUnmounted`).
   - Tampilkan data secara sederhana dan rapi (menampilkan Trafo ID, Beban kVA, Suhu Oli, Tegangan R/S/T, Arus R/S/T, dan Timestamp).
   - Berikan indikator status koneksi: "Terhubung (Realtime Aktif)" atau "Memuat data...".

Pastikan kode bersih, minim dependensi tambahan, dan siap dijalankan dengan perintah `npm run dev`.
